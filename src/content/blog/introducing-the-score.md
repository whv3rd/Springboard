"Are we using AI well?" is a hard question to answer honestly. Most teams can point to a few experiments. Fewer can say whether those experiments add up to anything.

The Springsboard Score is a quick, structured way to answer it.

## How it works

You rate each of the five checkpoints from 0 to 4:

| Rating | Meaning                                  |
| ------ | ---------------------------------------- |
| 0      | Not started                              |
| 1      | Partial, ad hoc                          |
| 2      | In place, not connected to AI            |
| 3      | Connected, used sometimes                |
| 4      | Connected and part of how work gets done |

Add them up and multiply by five. That gives you a score from 0 to 100.

## The five levels

| Score  | Level        |
| ------ | ------------ |
| 0–25   | Grounded     |
| 26–50  | Loading      |
| 51–75  | Coiled       |
| 76–95  | Launch-ready |
| 96–100 | Springsboard |

Expect a first score in Grounded or Loading. That isn't a criticism. It usually means the foundations exist in pieces but haven't been connected yet.

## Why a 2 isn't good enough

The rubric has one opinion built into it: having a system in place isn't the same as having it connected. A beautiful Figma library that no AI can use scores a 2. So does a clean catalog that still needs a developer for every bulk change.

The jump from 2 to 4 is where the leverage is.

## What you get

The free Score gives you your total, your level and one next step. A full gap report, with each checkpoint broken down and linked to the matching part of the Path, comes with Path membership.

The quiz takes a few minutes.
